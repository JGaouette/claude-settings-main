# Tech stack & starter template

**First, detect what's already there.** Without asking the user, check the codebase:

1. Read `CLAUDE.md` and/or `AGENTS.md` if either exists — these often spell out the stack and conventions.
2. Look at top-level config files: `package.json`, `composer.json`, etc.
3. Look at folder structure for framework signatures

**Then summarize what you found** to the user in plain language: "Looks like you're working in a Laravel app with Vue on the frontend."

**If detection is empty or ambiguous** (no clear stack found, or this is a fresh empty project), ask what the project tech stack is.
